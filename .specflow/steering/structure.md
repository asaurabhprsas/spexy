# Project Structure & Conventions

## Directory Conventions
- `packages/core`: Domain logic, schemas, and file engine.
- `packages/cli`: Command-line interface and daemon.
- `packages/ui`: Pre-bundled web dashboard.
- `skills/`: Agent skill contracts.
- `docs/`: Long-term project documentation and progress tracking.
